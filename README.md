# Vehicle Website

واجهة عربية RTL مبنية باستخدام Next.js App Router وTypeScript وTailwind CSS 4 وReact Icons.

## التشغيل

```sh
pnpm install
pnpm dev
```

لإصدار الإنتاج: `pnpm build` ثم `pnpm start`.

## اختبارات الموبايل

تكتشف إضافة **Playwright Test for VS Code** الإعداد في `playwright.config.ts` تلقائيًا. افتح تبويب **Testing** وشغّل `tests/mobile/responsive.spec.ts`، واختر مقاس الموبايل من ملفات التشغيل: 320 أو 360 أو 390 أو 430 بكسل. فعّل **Show browser** لمشاهدة الاختبار.

من التيرمنال: `pnpm test:mobile`، أو `pnpm test:mobile:ui` للواجهة التفاعلية. تُستخدم نسخة Edge المثبتة على Windows. هذه محاكاة لمقاسات الموبايل بمحرك Chromium، وليست اختبار Safari على جهاز iPhone فعلي.

الاختبارات تراجع عرض الصفحات، وهوامش بوكسات الحجز، وكروت الحساب، وفورم التسجيل، والشات. التقرير والصور داخل `playwright-report/`، وهي مستبعدة من Git.

## الصفحات

- `/`: الرئيسية والأسطول والخدمات.
- `/login`: تسجيل الدخول مع التحقق من المدخلات.
- `/signup`: حساب فردي أو شركة.
- `/forgot-password`: رقم الهاتف، رمز تجريبي، كلمة مرور جديدة.
- `/booking`: اختيار السطحة، بيانات الرحلة، المراجعة، التأكيد.
- `/orders`: فلترة الطلبات المحلية، عرض التفاصيل، وإلغاء الطلب الجديد.
- `/loading-screen`: معاينة شاشة التحميل. `app/loading.tsx` يعرضها عند انتظار تحميل المسار.

الكمبوننتس المشتركة داخل `components` والصفحات داخل `app`.

## حدود النسخة الحالية

هذه واجهة تجريبية، ولا توجد خدمة مصادقة أو SMS أو دفع أو إرسال سائق. رمز الاستعادة `1234` موضح في الواجهة. لا تُخزن كلمات المرور. الطلبات تحفظ باستخدام localStorage على نفس المتصفح، وهي بيانات غير محمية وغير مرتبطة بحساب حقيقي. الصور المرفقة تعرض اسم الملف فقط ولا ترفع لخادم. الأسعار توضيحية. تحديد الموقع يتطلب إذن المتصفح وHTTPS أو localhost.

اللغة الحالية هي العربية مع اتجاه RTL. النسخة الإنجليزية وتبديل اللغة لم يتم تنفيذهما. الخط من Google Fonts والصور من Unsplash وتتطلب اتصالًا بالإنترنت.
